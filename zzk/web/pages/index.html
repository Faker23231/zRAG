导入管线 · 8 步 一份 PDF → 可检索的双向量切片
01
  1. 01归档

    原始 PDF 先写入 MinIO，保留可追溯副本。

    MinIO
  2. 02校验

    按类型与大小分流，确定解析入口。

    Entry Router
  3. 03版面解析

    MinerU 云端 VLM 转成保留标题、正文与图片的 Markdown。

    MinerU · VLM
  4. 04图片归档

    视觉模型为每张图补一句图注，回写为在线链接。

    VL Model
  5. 05结构化切分

    标题粗切 + 300/50 递归细切，切片自带父标题。

    Text Splitter
  6. 06知识主体

    LLM 归纳文档级主体，再回填到每一条切片。

    LLM
  7. 07双向量

    BGE-M3 同时产出 1024 维稠密向量与稀疏权重。

    BGE-M3
  8. 08写入索引

    落库 Milvus，按 file_title 幂等覆盖旧版本。

    Milvus

02
  1. 01理解问题

    抽取知识主体并改写查询，带上对话历史上下文。

    LLM
  2. 02主体对齐

    主体库混合检索；0.80 命中，0.60–0.80 反问澄清。

    Clarify
  3. 03多路召回

    原始查询、HyDE 假设文档、MCP 联网三路并行。

    Hybrid Recall
  4. 04RRF 融合

    倒数排名加权合并两路向量结果，取前 10 条候选。

    RRF
  5. 05重排截断

    qwen3.7-text-rerank 打分，按断崖差动态决定 TopK。

    Rerank
  6. 06流式作答

    9000 字上下文窗口，逐 token 推送并把引用指回原文。

    Stream
